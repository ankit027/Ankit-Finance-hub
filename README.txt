# Ankit Finance Hub

Files:
- index.html
- style.css
- app.js
- Code.gs

IMPORTANT:
1. Deploy Code.gs as a Google Apps Script Web App.
2. Copy the /exec URL.
3. Open app.js and replace:
   PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE
4. Upload index.html, style.css and app.js to GitHub Pages.

This version is designed for cloud storage through Google Sheets / Apps Script.
